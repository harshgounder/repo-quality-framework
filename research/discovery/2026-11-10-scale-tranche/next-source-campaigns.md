# Next source campaigns for breadth at scale

These routes were located by independent research workers, not all harvested or independently checked in this tranche. A source route, item count, case report, test, design, estimate and quality obligation are different units. Inspect licenses, terms, privacy, machine-readable access, version and actual record definitions before ingesting; never publish sensitive individual data merely because a source is public.

## Scale plan and acceptance

For each **candidate class**—failure reports, observed mechanisms, components/algorithms, designs/architectures, tests/oracles, benchmarks/workloads, standards/obligations, tools/raters, measurements/estimates, roles/workflows, sources and others as discovered—maintain independent growth targets and progress. The user requested thousands per relevant element class, not a few examples overall. Targets do not establish that thousands of distinct, applicable or verifiable items exist in every narrowly defined class; search and report evidence instead of inventing items.

For each batch preserve immutable source-specific records, source and version, exact run and filters, pagination/cursor, retrieval time, record unit, access error, raw lead count, distinct source records, identity decisions, primary-source-opened count, appraised count, and in-scope evidence count. An issue is not automatically a defect, a file is not automatically a test, an incident is not automatically software-caused, and a proposal is not a deployed design. Canonical identities, duplicates, variants, aliases, changes over time, evidence contradictions and inapplicability need explicit decisions.

Use existing CSVs as exchange snapshots while designing a constraint-checked, versioned, append-only normalized store; this is a proposal, not an implemented database or decided product. Implement source-specific paginators, checkpointing, idempotent runs, full provenance and failure reporting before recurring large harvests. Human/reviewer appraisal and stratified counterexamples must keep pace; predeclare sampling and show per-source/per-domain progress, not just total rows. Expand venues, languages, geography and technical domains independently of these initial examples. Investigate measurement sources and methodologies before producing contextual estimates; never manufacture numerical estimates to reach a quota.
